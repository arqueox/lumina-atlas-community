## Lumina Atlas Community 0.1.0

First public Google TV APK. Install the attached `lumina-atlas-community-v0.1.0.apk`, open it, and enter the URL of your own Lumina Atlas server. Set up the server with your own Xtream compatible provider using the instructions in the repository README.

The TV client uses the same web interface for live TV, films, series, search, favourites, resume and playback. Its setup screen links to Android's Home app selection and accessibility settings. Select Lumina Atlas as Home only if your device offers that option; the app does not intercept the remote's Home key.

This release APK contains no provider credentials or private Hub token. It is signed with the project release key so later versions can update it. Build and signature checks passed; installation and Home behaviour on a physical Google TV Streamer 4K have not yet been verified.
